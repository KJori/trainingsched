      Coach

      The coach runs on an AI model from a provider you choose, with your own API key. Providers bill API use per request, separately from chat subscriptions such as Claude Pro or ChatGPT Plus, which don't include it. You can also run a model yourself with Ollama. The key stays on this server and is never sent to the browser or included in exports.
